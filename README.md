# AIML Practical Assignment 6
## Clustering Algorithms

### Objective
To implement different clustering algorithms
on a real-world retail dataset and evaluate
their performance.

### Dataset
UCI Online Retail Dataset

Dataset Link:
https://archive.ics.uci.edu/dataset/352/online+retail

### Algorithms Implemented
1. K-Means Clustering
2. Agglomerative Hierarchical Clustering
3. DBSCAN Clustering

### Evaluation Metrics
- Silhouette Score
- Davies-Bouldin Index
- Calinski-Harabasz Score

### Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

### Visualization
PCA-based cluster visualization and
performance comparison graphs.

### Execution
Open the notebook using Google Colab
and run all cells sequentially.
